# 2. Two-Sided Card and Vertical Combined Download

* **Status:** Accepted
* **Context:** Streamlining export options for attendees.
* **Decision:**
  1. Simplify downloads to a single primary action button: **"Download Builder ID"**.
  2. The single download generates a high-definition JPEG with Front and Back stacked top-to-bottom vertically.
  3. Clicking "Share to X" automatically copies the rendered image to clipboard so the user can paste the photo directly into their X post alongside the prefilled caption and `#HackerHouseGoa2026` hashtag.
* **Consequences:** Simplified download UX; seamless image clipboard integration with X sharing.
