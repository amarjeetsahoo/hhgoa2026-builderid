# HH Goa 2026 — Builder ID Studio

## Vision
A browser-based studio for Hacker House Goa 2026 attendees to generate high-definition builder badges, PFP avatar frames, and 2-sided flip cards with 3D preview. Built with Vanilla JS and HTML5 Canvas, preserving the authentic Dark Tropical Palm theme.

## Features
- **Format Toggle:** Switch between 2-sided **Builder ID Card** and 1:1 square **PFP Frame**.
- **Interactive 3D Card Preview:** Flip between Front and Back sides, with interactive 3D tilt effects.
- **Quick Stack Pills:** One-click role buttons (FULLSTACK, AI ENGINEER, SMART CONTRACTS, FRONTEND, BACKEND, DESIGNER, FOUNDER, DEVOPS).
- **Photo Adjustments:** Real-time drag pan, zoom scale, rotation, and filter controls.
- **Single Streamlined Download:** "Download Builder ID" exports a high-definition vertical top-to-bottom JPEG (Front + Back combined).
- **X Sharing:** "Share to X" copies the image to clipboard and opens X prefilled with `#HackerHouseGoa2026` for instant pasting.
- **Header Utility Links:** Direct links to Devfolio Registration, official site (hhgoa.com), and `#FrameInGoa`.
